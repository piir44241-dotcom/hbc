# হেক্সাবন্ড আল-বারাকাহ ক্যাপিটাল — হিসাব ব্যবস্থা (GitHub Pages)

## আগের (ফাইভফোল্ড) সাইট থেকে নতুন সংস্করণে যাওয়া — ২ মিনিট
1. আগের রিপোজিটরিতে **Add file → Upload files** চাপুন।
2. এই ফোল্ডারের `index.html`, `site.webmanifest`, `README.md` এবং পুরো `assets` ফোল্ডার টেনে ছেড়ে দিন → **Commit changes**।
3. `data` ফোল্ডারে হাত দেবেন না। আগের সব হিসাব, রসিদ ও পাসফ্রেজ আগের মতোই থাকবে। নাম, পদ ও শেষ তারিখ (১৫) নিজে থেকেই নতুন নিয়মে দেখাবে; অ্যাডমিন কোনো কিছু সংরক্ষণ করলেই তা স্থায়ী হবে।
4. চাইলে **Settings → General → Repository name** থেকে রিপোর নাম `hexabond` করতে পারেন। তখন সাইটের লিংক বদলে `https://ইউজারনেম.github.io/hexabond/` হবে, আর অ্যাডমিনের টোকেনে নতুন নামের রিপো বাছাই করা আছে কিনা দেখে নেবেন।

## লোগো বদলানো
সাইট, ব্রাউজার আইকন ও রসিদ — সবখানে লোগো আসে `assets` ফোল্ডার থেকে। নতুন লোগো দিতে চাইলে একই নামে ফাইল বদলে আপলোড করুন:
- `assets/logo-mark.svg` — হেডারের লোগো (না থাকলে `logo-mark.png` দেখায়)
- `assets/logo-mark.png` — রসিদের লোগো (বর্গাকার, ৫১২×৫১২ ভালো)
- `assets/favicon-32.png`, `assets/apple-touch-icon.png` (১৮০×১৮০), `assets/icon-192.png`, `assets/icon-512.png` — ব্রাউজার ও মোবাইল হোমস্ক্রিন আইকন
- `assets/logo-horizontal.png` — পূর্ণ লোগো (দরকার হলে ব্যবহারের জন্য)
ব্রাউজার পুরোনো ছবি মনে রাখলে একবার রিফ্রেশ করুন।

## মোবাইলে অ্যাপের মতো রাখা
মোবাইলে সাইট খুলে Chrome-এর ⋮ মেনু → **Add to Home screen** (আইফোনে Share → Add to Home Screen)। হোমস্ক্রিনে HBC আইকন থাকবে, অ্যাপের মতো খুলবে।

ছয় বন্ধুর মাসিক সঞ্চয়, রসিদ, ব্যাংকে জমার প্রমাণ, করজে হাসানা, বিনিয়োগ ও সভার সিদ্ধান্ত রাখার একটি ছোট ওয়েব অ্যাপ। এটি পুরোপুরি GitHub-এর ফ্রি সেবায় চলে। কোনো সার্ভার, ডেটাবেস বা মাসিক খরচ লাগে না।

## কীভাবে কাজ করে

- পুরো অ্যাপটি একটি ফাইল: `index.html`, সঙ্গে লোগো ও আইকনের `assets` ফোল্ডার আর `site.webmanifest`। GitHub Pages এগুলো ওয়েবসাইট হিসেবে দেখায়।
- সব হিসাব থাকে একই রিপোজিটরির `data/fund.enc` ফাইলে। প্রমাণের ছবি থাকে `data/proofs/` ফোল্ডারে।
- ফাইলগুলো **পাসফ্রেজ দিয়ে এনক্রিপ্ট** (AES-256)। রিপোজিটরি পাবলিক হলেও পাসফ্রেজ ছাড়া কেউ কিছু পড়তে পারবে না।
- **দেখতে** পারবেন যে কেউ, যিনি পাসফ্রেজ জানেন। এজন্য GitHub অ্যাকাউন্ট লাগে না।
- **লিখতে** পারবেন শুধু অ্যাডমিন (সাধারণত প্রধান অর্থ কর্মকর্তা), তার GitHub টোকেন দিয়ে।
- প্রতিটি সংরক্ষণ GitHub-এ একটি আলাদা কমিট হয়। তাই কবে কী বদলেছে তার স্থায়ী ইতিহাস থাকে, যা গোপনে মুছে ফেলা যায় না।

## প্রথমবার সেটআপ (অ্যাডমিন, সাধারণত প্রধান অর্থ কর্মকর্তা, ১৫–২০ মিনিট)

### ১. GitHub অ্যাকাউন্ট ও রিপোজিটরি
1. https://github.com এ একটি ফ্রি অ্যাকাউন্ট খুলুন (আগে থেকে থাকলে সেটিই চলবে)।
2. ডানদিকে উপরে **+** → **New repository**।
3. নাম দিন, যেমন `hexabond`। **Public** রাখুন (ফ্রি GitHub Pages-এর জন্য পাবলিক লাগে; ডেটা এনক্রিপ্ট থাকায় সমস্যা নেই)। **Create repository**।
4. রিপোজিটরির পেজে **Add file → Upload files** চাপুন। এই ফোল্ডারের `index.html`, `site.webmanifest`, `README.md`, `.nojekyll` ফাইল এবং পুরো `assets` ফোল্ডার টেনে ছেড়ে দিন। তারপর **Commit changes**।
   - `.nojekyll` ফাইলটি লুকানো থাকতে পারে। না দেখা গেলে **Add file → Create new file** দিয়ে `.nojekyll` নামে একটি খালি ফাইল বানান।

### ২. GitHub Pages চালু
1. রিপোজিটরির **Settings → Pages**।
2. **Build and deployment → Source**: *Deploy from a branch*।
3. **Branch**: `main` এবং `/ (root)` বাছাই করে **Save**।
4. ১–২ মিনিট পর উপরে লিংক দেখাবে, যেমন:
   `https://আপনার-ইউজারনেম.github.io/hexabond/`
   এটিই আপনাদের তহবিলের ঠিকানা।

### ৩. অ্যাডমিনের টোকেন বানানো
এই টোকেন দিয়ে অ্যাপ আপনার হয়ে ডেটা ফাইল সংরক্ষণ করবে। টোকেনটি পাসওয়ার্ডের মতো গোপন রাখবেন।
1. GitHub-এ প্রোফাইল ছবি → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**।
2. **Token name**: `hexabond-admin`।
3. **Expiration**: সবচেয়ে লম্বা মেয়াদ বাছুন। মেয়াদ শেষ হলে একইভাবে নতুন টোকেন বানিয়ে আবার লগইন করবেন।
4. **Repository access**: *Only select repositories* → শুধু `hexabond`।
5. **Permissions → Repository permissions → Contents**: **Read and write**। আর কিছু লাগবে না।
6. **Generate token** → `github_pat_...` দিয়ে শুরু হওয়া টোকেনটি কপি করুন।

### ৪. তহবিল তৈরি
1. Pages-এর লিংকটি খুলুন → উপরে **অ্যাডমিন লগইন** → টোকেন দিন → "এই ডিভাইসে মনে রাখুন" (শুধু নিজের ফোন বা কম্পিউটারে)।
2. "নতুন তহবিল সেটআপ" ফর্মে নাম, আপনার নাম আর একটি **পাসফ্রেজ** দিন। পাসফ্রেজ অন্তত ১২ অক্ষরের হবে, ভালো হয় কয়েকটা শব্দের একটা বাক্য হলে।
3. "সদস্য" ট্যাবে বাকি ৪ জনকে যোগ করুন এবং কে কোন যৌথ হিসাবে থাকবেন তা ঠিক করে দিন।

### ৫. বন্ধুদের দেওয়া
- লিংক আর পাসফ্রেজ আলাদা আলাদা পাঠান। সবচেয়ে ভালো হয় পাসফ্রেজ সামনাসামনি বলে দিলে।
- তারা লিংক খুলে পাসফ্রেজ দেবেন। "এই ডিভাইসে মনে রাখুন" দিলে পরেরবার আর চাইবে না। ফোনের হোম স্ক্রিনে বুকমার্ক রেখে দিতে পারেন।
- রসিদের ছবির নিচে প্রতিটি রসিদের নিজস্ব লিংক থাকে। খুললে দেখা যায় টাকা এখন হেফাজতে আছে না ব্যাংকে জমা হয়েছে।

## প্রতি মাসের কাজ

1. টাকা পেলে **+ চাঁদা গ্রহণ ও রসিদ** চাপুন। সদস্য, মাস, মাধ্যম ও TrxID দিন, বিকাশের স্ক্রিনশট থাকলে যুক্ত করুন। তারপর **ছবি পাঠান** বা **লেখা কপি** করে সদস্যকে পাঠিয়ে দিন।
2. হেফাজতের টাকা ব্যাংকে দিলে **খতিয়ান → + ব্যাংকে জমা**। কোন রসিদগুলোর টাকা জমা দিচ্ছেন সেগুলো টিক দিন, আর জমা স্লিপ বা ট্রান্সফারের ছবি দিন।
3. মাসের ১৫ তারিখে **মাসিক রিপোর্ট কপি** করে গ্রুপে দিন।
4. মাসে একবার **ব্যাকআপ / CSV → পূর্ণ ব্যাকআপ (JSON)** নামিয়ে গুগল ড্রাইভে রাখুন। এই ফাইল এনক্রিপ্ট করা নয়, তাই কাউকে শেয়ার করবেন না।

## জরুরি সতর্কতা

- **পাসফ্রেজ হারালে ডেটা আর খোলা যাবে না।** কাগজে লিখে অন্তত দুজনের কাছে রাখুন, আর নিয়মিত JSON ব্যাকআপ রাখুন।
- **টোকেন কাউকে দেবেন না**, গ্রুপেও পোস্ট করবেন না। টোকেন ফাঁস হলে GitHub-এর একই পেজ থেকে সেটি *Delete* করে নতুন টোকেন বানান।
- কোনো সদস্য চলে গেলে **সেটিংস → পাসফ্রেজ বদলান** দিন। খেয়াল রাখবেন, GitHub ইতিহাসের পুরোনো ফাইলগুলো পুরোনো পাসফ্রেজেই খোলা যাবে।
- দায়িত্ব অন্য কাউকে দিতে হলে তাকে রিপোজিটরিতে **Settings → Collaborators** দিয়ে যোগ করুন। তিনি নিজের অ্যাকাউন্টে টোকেন বানিয়ে লগইন করবেন।

## খরচ ও সীমা

- GitHub ফ্রি অ্যাকাউন্টে পাবলিক রিপোজিটরি আর GitHub Pages ফ্রি।
- ৬ জনের কয়েক বছরের হিসাব মিলিয়েও ডেটা ফাইল কয়েকশো KB হবে। প্রমাণের ছবি আপলোডের সময় নিজে থেকে ছোট করে নেওয়া হয় (প্রতিটি সাধারণত ১০০–৩০০ KB)।
- সাইন-ইন ছাড়া GitHub API-তে ঘণ্টায় একটি সীমিত সংখ্যক অনুরোধ করা যায়। সেই সীমা পেরোলে অ্যাপ নিজে থেকেই সাইটের কপি থেকে দেখায়, যা কয়েক মিনিট পুরোনো হতে পারে।

## অন্য কোথাও চালাতে চাইলে

`index.html` যেকোনো https সাইট থেকে চালানো যায়, যেমন Netlify বা Cloudflare Pages। সেখানে প্রথমবার খুললে অ্যাপ রিপোজিটরির নাম (`ইউজারনেম/রিপো`) জানতে চাইবে। ডেটা তখনও GitHub রিপোজিটরিতেই থাকবে।

## পদ ও নাম বদলানো

অ্যাপে ছয়টি সমমর্যাদার পদ আগে থেকে দেওয়া আছে: প্রধান অর্থ (CFO), প্রধান বিনিয়োগ (CIO), প্রধান ঝুঁকি ও কমপ্লায়েন্স (CRO), প্রধান প্রশাসনিক (CAO), প্রধান আইন ও চুক্তি (CLO) এবং প্রধান যোগাযোগ ও প্রযুক্তি (CCO) কর্মকর্তা। কোনো চেয়ারম্যান বা প্রধান নেই। সভায় অন্য নাম ঠিক হলে **সেটিংস → পদসমূহ** থেকে বাংলা নাম, ইংরেজি নাম ও দায়িত্ব বদলাতে পারবেন, নতুন পদও যোগ করতে পারবেন। কে কোন পদে আছেন তা **সদস্য** ট্যাবে প্রত্যেকের "সম্পাদনা" থেকে ঠিক করবেন।
